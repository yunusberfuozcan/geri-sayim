# Geri Sayım

macOS masaüstünde, pencerelerin arkasında duran bir geri sayım kartı.

- Başlık, tarih ve saat uygulama içinden ayarlanır (karta sağ tık ya da menü çubuğundaki ⏳).
- Kart sürüklenebilir, konumu hatırlanır.
- İsteğe bağlı: "Mac açılınca başlat".

## Kurulum

```bash
zsh build.sh
```

`~/Applications/GeriSayim.app` olarak derler, kurar ve başlatır. macOS 14+ ve Xcode Command Line Tools gerekir.
